TASK 4: Microservice RBAC with JWT & Message Broker
========================================
Location: task-4-microservice-rbac/

✅ COMPLETED & TESTED
- Architecture: Microservices (3 services)
- Auth: JWT tokens with Role-Based Access Control
- Message Broker: RabbitMQ (with in-memory fallback)
- Containerization: Docker Compose ready

Services:
1. Auth Service (Port 5001)
   - User registration
   - JWT token generation
   - Token verification
   - Password hashing with bcrypt

2. API Service (Port 5002)
   - Protected endpoints with JWT
   - Role-based permission checks
   - CRUD operations on resources
   - Async task queuing

3. Worker Service (Port 5003)
   - Background task processing
   - Message queue consumer
   - Async operation handling

RBAC Roles & Permissions:
- ADMIN: Full access (read/write/delete all resources)
- USER: Read and write data, read reports
- GUEST: Read-only access

Default Users:
- admin/admin123 (admin role)
- user/user123   (user role)
- guest/guest123 (guest role)

How to Run:

Option 1 - Without Docker (Local):
1. cd task-4-microservice-rbac
2. npm install
3. Open 3 terminals:
   Terminal 1: npm run auth     (port 5001)
   Terminal 2: npm run api      (port 5002)
   Terminal 3: npm run worker   (port 5003)
4. npm test                     (run automated tests)

Option 2 - With Docker:
1. cd task-4-microservice-rbac
2. docker-compose up -d
3. npm test
